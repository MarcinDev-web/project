Launching Forge Engine — WebGPU 3D engine + in‑browser editor (TypeScript)

Today I’m open‑sourcing Forge Engine: a WebGPU‑first 3D engine with a professional scene editor that runs entirely in the browser. 

Why this matters:
- Modern graphics on the web (WebGPU, PBR, shadows)
- Fast iteration with a real editor + visual scripting
- TypeScript end‑to‑end for readable, testable code

Highlights:
- Forward+ renderer, PBR materials, cascaded/point shadows
- Editor: snapping, history, play mode, timeline
- Visual scripting (LogicCubes) for rapid prototyping
- Modular @engine/* packages with strict boundaries
- Strong testing & CI in the repo
