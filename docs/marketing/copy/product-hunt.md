## Product Hunt — Launch Copy

Title: Forge Engine — WebGPU 3D engine + pro editor in your browser (TypeScript)

Tagline: Build modern 3D games and interactive worlds on the web. WebGPU‑first, TypeScript, open‑source — with a professional in‑browser scene editor and visual scripting.

What it does
- WebGPU 3D engine in TypeScript with PBR, shadows, Forward+ rendering
- Professional in‑browser scene editor (history, snapping, play mode)
- Visual scripting (LogicCubes) for fast gameplay prototyping
- Multiplayer building blocks and modular packages (@engine/*)
- Production quality: strict TS, tests, CI, performance guidelines

Why it matters
- No native installs — create and share instantly in the browser
- Modern graphics with WebGPU, not legacy WebGL hacks
- Learnable, testable stack for teams that prefer TypeScript
