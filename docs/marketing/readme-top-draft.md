# Forge Engine

Modern WebGPU 3D engine + professional in‑browser editor (TypeScript)

Build and ship 3D games and interactive worlds on the web. WebGPU‑first performance, visual scripting, multiplayer building blocks — all in TypeScript, all in your browser.

— Demo: <add link> · Repo: <add link> · Docs: <add link>

## Why Forge?
- WebGPU performance, PBR materials, shadows, Forward+ pipeline
- Professional editor: snapping, history, play mode, timeline
- Visual scripting (LogicCubes) to prototype gameplay fast
- Modular @engine/* packages with strict boundaries
- Production standards: TS strict mode, tests, CI, performance guidelines

## Quick Start
```bash
pnpm install
pnpm build
pnpm dev   # run the editor with hot reload
```
