## Forge Engine — Positioning, ICPs, UVP

### One‑liner
Forge Engine is a WebGPU‑first, TypeScript 3D engine with a professional in‑browser scene editor, multiplayer, and visual scripting — production‑grade, open‑source, and ready for the web.

### Elevator pitch
Build modern 3D experiences directly in the browser without native installs. Forge pairs a high‑performance WebGPU renderer and modular TypeScript engine with a professional editor and visual scripting, so you can prototype fast, collaborate, and ship production‑quality games and interactive worlds on the web.

### Ideal Customer Profiles (ICPs)
- Indie developers and small studios
  - Need: Browser‑native stack, fast iteration, pro editor tools, multiplayer.
  - Value: WebGPU performance, ECS architecture, visual scripting, strong testing.
- Web developers adding 3D to apps/sites
  - Need: TypeScript APIs, simple deploys, no plugins, web‑first rendering.
  - Value: All‑TS engine, Vite/Vitest workflow, zero native runtime.
- Educators and students
  - Need: Learnable stack, good docs, runs on school laptops, shareable results.
  - Value: TS + WebGPU, editor in browser, reproducible projects.
- Technical creators/OSS tinkerers
  - Need: Modular packages, clean boundaries, testable code, extensibility.
  - Value: Monorepo packages (@engine/*), strict mode, reusable utilities.
- Agencies/brands building interactive 3D
  - Need: Reliable platform, quick demos, on‑brand visuals, analytics hooks.
  - Value: Pro editor, PBR/shadows, componentized systems, deploy anywhere.

### Problems solved
- Browser‑native 3D with modern performance (WebGPU, PBR, shadows, Forward+)
- Full toolchain in one repo: engine, editor, networking, stdlib
- Fast iteration: hot reload, visual scripting (LogicCubes), scene editor
- Production rigor: TypeScript strict mode, testing utilities, CI
- Modular architecture: clear boundaries, package reuse, no spaghetti imports

### Differentiators
- WebGPU‑first and browser‑native (no native runtime, share instantly)
- Professional in‑browser editor (play mode, snapping, history, timeline)
- Visual scripting (LogicCubes) for rapid prototyping
- TypeScript end‑to‑end: readable, testable, maintainable
- Multiplayer‑ready building blocks and platform packages
- Strong docs and quality gates (coverage, linting, disposables, performance)

### Value propositions by ICP
- Indie/small studios: Ship web‑based 3D faster; editor + scripting cuts iteration time; multiplayer basics included.
- Web devs: Stay in TS; no C++/native; deploy on any static host/CDN; integrate with existing tooling.
- Education: Students learn modern graphics with TS/WebGPU; no installs; assignments run in browser.
- OSS tinkerers: Clean packages, enforced boundaries, reusable utilities; contribute without massive context.
- Agencies: Demos in days, not weeks; consistent visuals; deploy to brand sites without plugins.

### Core messaging pillars
1) WebGPU performance, browser‑native
2) Professional editor + visual scripting
3) Modular TypeScript engine with strong quality bar

### Taglines (options)
- WebGPU 3D engine and pro editor — in your browser, in TypeScript.
- Build, play, and ship 3D on the web — fast, open, production‑ready.
- TypeScript + WebGPU for modern 3D games and interactive worlds.

### Primary call to action
Try the editor, build a small scene, and share the link — no install required.
