# @engine/voxel

**Voxel/Microblock System** - Chunk-based voxel rendering (przyszłość).

## Zawartość (Planowane)

- **ChunkStore** - Voxel data storage
- **ChunkMesher** - Worker-based greedy meshing
- **ChunkStreamingSystem** - LOD and streaming
- **Microblocks** - Subvoxel precision

## Zależności

- `@engine/core`
- `@engine/world`
